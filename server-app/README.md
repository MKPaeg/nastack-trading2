# 상용 서버 앱

운영자 PC에서 기존 NaStack 거래 기능과 관리자 기능을 제공하고, 게이트웨이에서 승인된 LLM 요청을 내부 인증 채널로 처리할 예정이다. 관리자는 일반 기능을 사용할 때 자신의 사용자/테넌트 데이터만 이용한다.

`src/`, `migrations/`, 웹 자산, 의존성 잠금 파일, Dockerfile 및 테스트는 v0.5.0 기준 서버에서 복사한 독립 코드다. 이후 두 서버의 수정은 자동으로 동기화되지 않는다. 필요한 보안 수정은 양쪽에 명시적으로 적용하고 각각 테스트한다. 프로젝트명·DB 볼륨·설정 파일·호스트 포트는 기존 8080 서버와 분리된다.

`python3 create_env.py`로 `.env.next`를 만들 수 있다. 실행 전 `docker compose --env-file .env.next -f compose.yaml config`를 확인하고, 실제 기동은 [계획의 검증 단계](../PLAN.md)에 따라 진행한다. 운영 거래 서버의 기존 설치 스크립트와 실행기는 사용하지 않는다.
