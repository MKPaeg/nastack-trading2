1.10.6 사용자별 LLM 사용 이력: 기존 호출별 모델·토큰·비용 표시와 동일한 OpenAI 공식 단가 경로를 유지한다. 새 DB에는 인증 세션 사용자·테넌트, 호출 시각(UTC)·서울 날짜, 모델·공급자, 수집/평가 유형, 보고된 입력·출력·캐시 토큰과 그날 확인한 USD 추정액만 저장한다. 프롬프트·응답·키·계좌는 저장하지 않는다. 일·주·월·연 조회는 사용자 소유 기록만 집계하며 비용 미확인 호출을 0달러로 간주하지 않는다. 기존 실행 이력은 소급 재계산하거나 덮어쓰지 않으며, 이 기능 도입 이전의 호출은 새 이력에 자동 반영되지 않는다.

1.10.5 비용 분해 보완: OpenAI가 보고한 기본 30분 캐시 쓰기 토큰을 일반 입력 토큰과 중복 합산하지 않고 모델별 공식 캐시 쓰기 단가로 계산한다. 캐시 쓰기 수량이 미보고되거나 12시간 유지 등 현재 가격 해석 범위 밖이면 비용 미확인으로 표시한다. 여러 모델이 섞인 실행은 호출 모델별 사용량·예상 비용을 분리하여 표시한다. 토큰·사용자별 기존 작업 이력은 그대로 보존하고 이미 저장된 예상액은 소급 변경하지 않는다.

1.10.4 LLM 가격 조회: 기존 2026-10-27 고정 5개 모델 단가와 2026-11-21 만료 규칙을 현재 선택 모델의 공식 상세 가격 페이지 확인으로 대체한다. 비용 계산이 실제로 필요할 때 모델별로 서울 날짜 기준 최초 1회 공개 HTML을 조회하고 같은 날 재사용한다. 실패 시 1시간 후 재시도하며 전날 단가로 추정하지 않는다. Standard·짧은 문맥·텍스트 입력/캐시 입력/출력의 공개 USD/100만 토큰 단가만 적용한다. 캐시 쓰기·긴 문맥·비표준 처리·미보고 사용량은 비용 미확인이다. 모델 목록 조회는 단가 조회가 아니며, 가격 조회는 추론·유료 모델 호출이 아니다. 과거 실행 금액은 재계산하지 않는다.

1.10.3 매매 카드 테두리 표시: 현재가·등락률을 카드로 감싸고 매매 설정·예측·손익 카드 배경을 표의 각 행/hover 배경과 일치시킨다. 테두리와 밝은 배경용 글자색으로 구분하며 입력창과 상태 표시는 기능별 색상을 유지한다. 외부 데이터·계산·주문 정책·개인 설정은 그대로다.

## 1. 범위와 읽는 방법

이 문서는 NaStack Trading이 외부에서 받는 데이터를 데이터 항목 중심으로 정리한다. 증권사 시세뿐 아니라 계좌·잔고·체결, 종목 마스터, 공시, 검색 발췌, 경제 통계와 외부 모델 응답을 포함한다. 코드에 구현된 수집 경로와 아직 연결되지 않은 후보를 구분한다. 사용자별 활성 설정·API 권한·저장 성공은 구현 여부와 다르다. 이 문서는 개인 계좌·키·이메일·기사 원문을 포함하지 않는 공용 기술 문서다.

- 구현: 수집 코드가 존재함. 이번에 모든 계열을 실제 호출했다는 뜻은 아님.
- 실수신 확인: 이전 승인된 실행에서 실제 관측값이 확인된 항목. 장기 안정성 보장은 아님.
- 후보: 문서·목록에 있으나 앱 수집 경로가 연결되지 않음.
- 미확인: 공개 명세에서 해당 기능을 확인하지 못함. 서비스 전체에 없다는 단정이 아님.
- 계열 ID, 실제 상품, 단위, 관측일, 발표시각, 조회시각, 수정 여부, 원지표/대용치를 각각 보존한다.

대상은 최초 점검 당시 카탈로그 113개 중 can_collect=false였던 25개다. 기존 TAIEX는 제외했다. 25개 모두에 주 후보·대안·다음 작업을 배정했고, 공개 접근 범위에서 후보를 테스트했다. **15개 항목에서 숫자 자료를 확인**했다(세계은행 월평균 12개, KOMIS 광물 2개, ASX 월말 1개). 나머지 10개는 숫자 시계열을 확보하지 못했다. 표의 ‘차단’은 이번 환경·경로의 결과이며 서비스 전체에 데이터가 없다는 뜻이 아니다.

자료 수신과 운영 연결은 별개다. 최초 v1.0은 계획·공개 원천 검증만 수행했다. v1.1에서는 우선 8개에 월간 수집·조회 경로를 구현했다. v1.2에서 커피 Arabica·고무 RSS3 2개를 추가했다. v1.3에서 IMF 철광석과 2026년 이후 팜유를 추가해 이후 v1.4에서 VKOSPI 개인 연결 조건부 일별 경로를 추가했다. 현재 수집 코드 101개(기존 일별 88 + 월간 12 + 개인 검증 조건부 VKOSPI 1), 미구현 12개다. 개인별 실제 수집 가능 수는 키 활성·연결 테스트 결과에 따라 다르다. 최초 후보 25개 ID는 진행 추적을 위해 표에서 유지한다. 월간 8개도 월간 벡터/상관분석까지 완료한 것은 아니다. 운영 DB·개인 키·수집 한도·종목 목록·주문을 변경하지 않았다. 유료 LLM·뉴스 검색 API 호출 0회, 운영 DB에 새로 저장한 관측 0건. 인증·계약을 우회하지 않았다.

## v1.1 연결 진행 현황

아연·알루미늄·납·주석·Dubai·TTF·대두유·면화 8개: **월간 원자료 수집 구현·새 파서 실수신 확인·격리 테스트 통과**. 다차원 데이터에서 선택 후 수동 수집할 수 있다. 월말은 관측월의 표기이고 당시 공표일이 아니다. 월평균은 원빈도로만 저장·표시한다. 일별 벡터/예측·기본 차원 자동 제안에서 제외하고 서버에서도 일별 입력을 거부한다. 새 계열은 수동 전용으로, 기존 자동 수집 설정을 변경하지 않는다. 본인 운영 계정의 수집 성공은 사용자가 실제 실행한 뒤 별도로 확인한다.

실제 운영 파서 검증에서는 공식 홈페이지에서 현재 Monthly prices XLSX 링크를 발견하고 파일을 1회 내려받아 8개 열을 각각 파싱했다. 모두 2020-01~2026-09 양수 81개월·결측 0건이다. 최초 검증에서 비대상 열의 Excel 오류 셀 때문에 파일 전체가 거부되는 문제를 발견해, 대상 가격 셀은 엄격하게 검증하되 비대상 열 오류는 허용하도록 보완한 뒤 실자료로 재검증했다. 정확한 헤더·단위·Monthly Prices 시트·월 중복·문서 갱신일·미래 관측을 검사한다. XLSX 입력 크기 2MB·압축 해제 총량 20MB·파일 수 100 제한, DTD/엔티티·암호화 ZIP·임의 URL·리다이렉트는 거부한다. 캐시는 공용 파일이 아닌 사용자별 저장 배치를 재사용하며 24시간 이후 선택 구간을 다시 확인해 수정·신규 월을 검토한다.

공개 실응답 요약: docs/research/external-data/probes/2026-10-26-161210-wb-runtime-parser.json. 파일명 시각은 UTC, checked_at도 UTC이며 한국 시각 2026-10-27 01:12에 해당한다. 운영 DB를 사용하지 않았다. 수집 코드는 dimension_worldbank.py, 확인 도구는 scripts/check_worldbank_monthly.py다.

다음 표를 기준으로 ID를 유지하며 갱신한다. 완료 단계는 **정의 합의 → 관측 수신 → 품질/이용권 통과 → 수집기 구현 → 격리/회귀 검증 → 운영 확인**이다. ‘수신 확인’만으로 ‘구현 확인’ 표시를 켜지 않는다. 담당은 개발이며, 유료 계약·새 바스켓·월간 분석 채택은 사용자 결정이 선행한다. A/B/C는 구현 순서이지 완료율이 아니다.

## v1.3 남은 15개 재검토

모든 15개를 다시 검토했다. IMF 철광석·교체 이후 팜유 2개는 수집 구현하고, 나머지 13개는 정확한 공식 지수 미확인 3개와 인증/이용권/실자료 확인 대기 10개다. 사용자 요청대로 섹터는 ETF·임의 바스켓으로 대체하지 않는다. OpenDART 공시·재무는 원자재 가격이나 원지수의 대체 자료가 아니다. 공개 경로 11개를 각 1회 재점검했으며 200/401/403/404 결과를 증거 07에 기록했다. ASX는 새로 확인한 약관의 자동 접근 및 S&P 지수값 저장 금지 때문에 연결을 보류한다. 원지수/상품의 권리를 우회하지 않는다.

## v1.4 VKOSPI 개인 연결

KRX 설정에 연결 테스트 버튼을 구현했다. 본인 키로 최근 완료 거래일의 파생상품지수 API를 최대 3거래일 확인해 정확한 VKOSPI 행·기준일·양수 종가가 있을 때만 성공한다. 테스트는 관측을 수집 DB에 저장하지 않는다. 성공하면 본인의 국가·시장 목록에서 KOSPI 바로 위에 표시하며 저장 자료 필터에도 연결 확인 항목을 표시한다. 과거 미수집 제외가 있었다면 테스트 시작 당시의 본인 VKOSPI 제외만 복원하고 감사 이력을 남긴다. 다른 차원·사용자 목록은 변경하지 않는다.

수동 수집은 기준일별 최대 5거래일만 읽고 미조회 구간을 남긴다. 설정/화면 진입으로 수집하지 않으며 자동 정기 수집·차원 자동 제안·일별 예측 입력에서 제외한다. 요청마다 사용자 권한/개인 키 버전을 확인하고, 중간 변경 시 중단·결과 적용 거부한다. provider=krx_vkospi, series=VKOSPI, source_version=krx-vkospi-eod-v1 및 개인 connection_version으로 이력/캐시를 분리한다. 운영 개인 키·API·관측 DB는 검증에 사용하지 않았다.

ASX는 공식 페이지의 연도 탭과 표를 대조해 2026년 첫 가격표 9행을 확인했다. 앞의 All Ordinaries 열이 아닌 세 번째 S&P/ASX 200 price index 열이다. 월말 관측을 월평균이나 일별 종가로 표시하지 않는다. 과거 표는 존재하지만 모든 연도의 값·연결·개정까지 검증한 것은 아니다.

KOMIS 가격 응답은 코드·기준·단위·원천명을 대조하고 모든 반환행의 날짜 파싱/양수/중복을 확인했다. 코발트 182행, 흑연 192행은 모두 양수이고 중복일 0이었다. 두 계열 모두 최초 2026-01-04, 최신 2026-10-23이며 주말 날짜 4개가 있다. 주말 관측을 임의 삭제하거나 다음 거래일에 붙이지 않는다. 원문 해시와 요약만 보존하고 전체 가격 시계열은 보고서로 재배포하지 않는다. KOMIS는 2026-01 이후 자료원 변경을 공지했고, 저작권 정책에 이용 협의 조건이 있어 앱 정기 수집은 아직 승인하지 않는다.

실패/제한도 증거로 남겼다. IMF XLSX 403, LME HRC 페이지 403, Platts 목록 403, STOXX 과거 URL 404, KRX sample 401. KOMIS·SCFI·HSI·FTSE의 HTML 200을 숫자 수집 성공으로 집계하지 않았다. 이 결과를 공급자 자체 장애 또는 데이터 부재로 단정하지 않는다. 브라우저 웹 검색에서 읽힌 페이지와 이 서버의 HTTP 접근 결과가 다를 수 있다.

## 구현 순서와 공통 완료 조건

1. **A - 월간 경로부터:** 아연·알루미늄·납·주석·Dubai·TTF·대두유·면화 8개를 우선 구현 후보로 한다. 커피·고무 2개는 품종/규격 선택 후 합류. 일별 수집기에 연결하기 전에 월간 관측·공표일·사용가능일과 월간 상관/벡터 계산을 지원한다. 일별 화면에 20거래일 복제해 표본을 부풀리지 않는다. 최소 60개월 중 유효 교집합 36개월 이상이라는 초기 품질 기준을 두고, 부족하면 추정 불가로 유지한다.
2. **B - 품질/권한 해결:** 철광석 단위, 팜유 단절, KOMIS 2개 이용권·캘린더, VKOSPI 키·정확한 행을 해결한다. ASX는 월말 보조 경로와 일별 목표를 분리한다. 각 차단 조건이 해결된 항목만 A/C 구현에 합류한다.
3. **C - 정의/계약:** 3개 섹터 바스켓을 먼저 정의·승인한다. HRC·JKM·SCFI·HSI·STOXX·FTSE 6개는 권리 있는 원계열 feed 확보 전 완료로 표시하지 않는다. API 키가 없는 계약 서비스에 임의 가입하거나 비용을 결제하지 않는다.
4. **회귀/격리와 운영 승인:** 파서 실패·결측·단위 변조·중복·공표 지연·정정/개정·수집 중단을 모킹한다. 같은/다른 테넌트 A/B, 조회 전용/일반/관리자, 비활성 개인 연결, 계정 전환, 키 버전 변경, 직접 객체 ID 접근을 검증한다. 공용 가격 캐시와 개인 수집·분석 상태를 분리한다. UI의 성공·구현·최신성 표시를 각각 확인한 뒤 운영 반영한다.

월간 자료는 월말에 이미 알려졌다고 가정하지 않는다. 이번 파일은 10-02 갱신, 최신 관측은 9월이다. 과거 공표일/수정 vintage를 확보하지 못하면 역사 백테스트에 투입하지 않고 최신 분석만 허용하거나 보수적 지연 정책을 명시적으로 승인받는다. 미래값 선취를 막기 위해 관측월·공표일·조회시각을 별도 필드로 보존한다. 보간은 기본 비활성이고 적용 시 관측값이 아닌 추정값이라는 표시와 별도 계열 버전이 필요하다.
