# 외부 데이터 변경 이력

공용 기술 정의 변경만 기록한다. 계좌·사용자 식별자·API 키·기사 원문은 기록하지 않는다. 자동 산출물의 버전·SHA-256 목록은 external-data/history/manifest.json에 누적된다. 소스 교체 시 이전 값→새 값, 사유, 의미 동일 여부, 검증·재계산·복구 계획을 이 파일에 추가한다.

## 1.10.8 - 2026-10-28

- 이전 1.10.7: 새 소스 지문과 캐시 쓰기 계산 정책을 스냅샷에 기록했지만 정본 목록 본문의 기준일·현재 버전 표기는 1.10.6이었다. 새 값: 정본 본문·PDF의 기준일을 2026-10-28, 현재 버전을 1.10.8로 정정하고 30분 캐시 쓰기 1.25배 적용 범위를 명시한다. 공급자·경로·계열·단위·주기·라이선스·권한이나 실제 수집 자료는 변경하지 않는다.
- 의미/검증/영향/복구: 문서 메타데이터 정정이며 토큰 산식과 원천 데이터 의미는 1.10.7과 같다. 오프라인 전체 목록·PDF·JSON 지문 검증 및 PDF 첫/끝 페이지 렌더링으로 표기를 확인한다. 개인 이력·관측·주문 재계산은 없으며 이전 불변 스냅샷은 그대로 보존한다.

## 1.10.7 - 2026-10-28
