# NaStack 상용 아키텍처 작업 공간

세 앱을 이 폴더에서 함께 개발한다. 기존 8080 거래 앱은 `/Users/munki/project/nastack-trading`에서 별도로 개발·운영한다.

| 폴더 | 배포 단위 | 담당 영역 |
| --- | --- | --- |
| `server-app/` | 운영자 PC의 서버 | 기존 거래 앱을 기반으로 운영자 일반 기능·관리 기능과 내부 LLM 처리 |
| `gateway-app/` | 운영자 PC의 공개 HTTPS 서비스 | 등록·승인·앱키·플랜·결제·LLM 요청 중계 |
| `client-app/` | 고객 Mac/Windows | 브로커 한 종류의 1인용 로컬 거래 앱 |

진행 상태와 검증 기준은 [PLAN.md](PLAN.md)에 기록한다. `server-app/`은 v0.5.0 서버 코드를 복사한 독립 빌드 단위다. 기존 루트 서버는 계속 별도로 개발할 수 있다. 클라이언트와 게이트웨이는 계약 문서만 준비된 상태다.

## Git 작업 방식

이 폴더는 기존 서버 저장소와 독립된 Git 저장소로 관리한다. 기본 브랜치는 `main` 하나이며 앱별 작업이 겹칠 때만 짧은 기능 브랜치를 만든다. 배포물은 앱별로 빌드하고 계약 호환성은 통합 테스트에서 확인한다. 기존 서버의 변경은 자동으로 들어오지 않으며 필요한 수정만 검토해 양쪽에 적용한다. GitHub 원격 저장소는 `MKPaeg/nastack-trading2`에 연결한다.

Codex의 `nastack-trading2` 프로젝트에는 이 폴더 자체를 기본 작업 폴더로 등록한다. 앱별 병렬 작업은 각 폴더를 맡는 별도 채팅에서 진행하고, 동일 파일을 동시에 수정할 때만 기능 브랜치를 사용한다. 원격 저장소는 `https://github.com/MKPaeg/nastack-trading2`에 연결되어 있다.
