# NaStack 개인 클라이언트 (개발 예정)

브라우저에서 사용하는 1인용 로컬 앱이다. macOS와 Windows 11을 지원하며 설치 패키지는 후속 단계에서 만든다. 나무증권판과 키움증권판은 동일한 핵심 코드에서 빌드하되 한 설치에서는 브로커 하나만 선택·설정·호출한다.

## 경계

- 로컬 DB에는 해당 사용자 계좌·설정·거래·분석 이력만 저장한다. 브로커 자격증명은 로컬 암호화 저장하고 게이트웨이로 보내지 않는다.
- 주문과 체결 조회는 로컬 앱이 선택한 브로커에 직접 요청한다. 설치·로그인·설정 저장만으로 주문을 실행하지 않는다.
- LLM 요청만 공개 도메인의 게이트웨이를 거쳐 운영 서버로 전달한다. 앱키는 로컬 백엔드에만 저장하고 브라우저 JavaScript에 노출하지 않는다.
- 관리자 API와 관리 UI는 클라이언트 빌드에서 제공하지 않는다. 서버 라우트 차단 테스트가 필요하다.
- 등록·승인·요금제·한도와 무관하게 로컬 거래 기능의 안전 잠금은 독립적으로 유지한다.

현 단계는 폴더와 계약 문서만 준비했다. 설치·인증·LLM 호출·실거래 코드는 아직 제공하지 않는다. 상용 배포 전 브로커별 설치물과 서명·업데이트 체계를 확정한다.
