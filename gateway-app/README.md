# NaStack LLM 게이트웨이 (개발 예정)

인터넷 도메인의 HTTPS 종단점으로 운영한다. 클라이언트 등록·승인·앱키·요금제·사용량·결제 웹훅을 담당하고, 승인된 LLM 요청만 운영 서버의 내부 API에 위임한다. 트레이딩 주문 API는 게이트웨이에 노출하지 않는다.

## 예정 계약

- 등록: 설치 식별자와 소유자 이메일을 받고 `pending` 상태로 생성. 운영 관리자 승인 전 LLM 호출 불가.
- 키: 고엔트로피 키를 1회만 표시하고 DB에는 해시만 저장. 활성/중지/폐기/재발급과 이력 기록. 키 단독으로 계좌·주문·관리 API 접근 불가.
- 호출: 요청별 키, 사용자·테넌트·설치, 플랜 기간과 상태, 사용량 한도를 재검증. 멱등성 키로 재시도 중복 과금 방지. 결과·캐시는 사용자/테넌트/입력/모델/프롬프트 버전별 분리.
- 결제: 결제대행사 웹훅 서명과 이벤트 ID 검증 후 권한을 변경. 브라우저 복귀 URL이나 결제 성공 화면만으로 플랜 활성화 금지.
- 운영: 공개 HTTPS 프록시, 속도 제한, 감사 로그, 요청 본문/비밀값 마스킹. 내부 서버와 별도 비공개 연결.

현 단계에는 실행 서버나 결제 연동이 없다. 실제 결제대행사 선택 및 계약 후 개발한다. 공개 도메인·HTTPS 인증서·웹훅 URL은 운영 환경에서 분리해 관리한다.
